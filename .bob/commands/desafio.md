- **Tecnologia:** use "$1" como linguagem/tecnologia base do desafio. Se não for informada, escolha uma aleatoriamente dentre: Python, JavaScript, Java, Go, Rust, TypeScript.

  - `Avançado` → concorrência, otimização, design patterns, algoritmos complexos
  - Se não informado, escolha aleatoriamente um dos três níveis.
